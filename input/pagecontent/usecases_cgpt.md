# Use Case-katalog for FHIR-baseret henvisningshåndtering

## Introduktion

Dette dokument beskriver de identificerede use cases for FHIR-baseret
henvisningshåndtering. Hver use case er dokumenteret separat med formål,
aktører, relationer og plads til PlantUML-diagrammer.

## Oversigt

-   Henviserens use cases
-   Visitatorens use cases
-   Dialogbaserede use cases
